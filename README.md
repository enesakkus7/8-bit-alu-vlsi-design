# 8-Bit ALU – VLSI Design & Physical Layout

**Academic Project | Gebze Technical University | 2025–2026**

**Course:** ELEC 451 – Introduction to Digital Integrated Circuits

## Project Overview

This project focuses on the design and physical layout of an 8-bit Arithmetic Logic Unit (ALU) using CMOS VLSI design methodologies.

Developed collaboratively by a five-member engineering team, the project covers RTL design using Verilog HDL, transistor-level circuit design, physical layout implementation, and simulation-based verification of arithmetic and logical submodules.

The project was developed as part of the Introduction to Digital Integrated Circuits course at Gebze Technical University, using Synopsys-based design tools and a project specification targeting 90 nm CMOS technology.

## Supported Operations

The ALU architecture includes nine operations:

- Addition and subtraction
- Multiplication
- Bitwise AND, OR, XOR, and NOT
- Logical left and right shifts

Operation selection is controlled through opcode decoding.

## Design Methodology

The project followed a hierarchical VLSI design approach:

1. **RTL Design:** Modeling arithmetic, logical, and shifting operations using Verilog HDL.
2. **Transistor-Level Design:** Developing CMOS-based circuit schematics for individual functional blocks.
3. **Physical Layout:** Creating physical layouts of ALU submodules using Synopsys tools.
4. **Simulation and Verification:** Testing functional behavior and analyzing post-layout parasitic effects for the implemented submodules.
5. **Technical Documentation:** Documenting circuit architectures, schematics, layouts, simulation results, and verification status.

## Technologies and Concepts

## Project Results

RTL-level design of the integrated 8-bit ALU was completed. The main arithmetic, logical, and shifting submodules were implemented and verified through schematic, layout, and post-layout stages, as documented in the project report.

The full integrated ALU was not verified at the complete physical-layout level. Some status-flag functionality, including overflow detection, remained outside the completed implementation.

## Team Collaboration

This project was completed collaboratively by a team of five Electronics Engineering students. All team members participated in the design, implementation, analysis, and documentation processes.
